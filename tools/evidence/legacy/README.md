# Historical archive readers

These unchanged validators read the retired prototype's archive formats. They
are retained for checking old public evidence, not used by current build or
deployment workflows. `image-verify.sh` also loads a previously checked image;
that operational step requires separate deployment authorization.

The complete producer, original tests, native process bounds and browser
round-trip fixtures remain in Git history at
`c653ed8a579592a5d4383d0f9a1ca380c387b20a`. See
[the retirement record](../../../docs/retired-prototype.md).
